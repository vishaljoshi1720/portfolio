# Vishal Joshi — Portfolio

Freelance portfolio for React Native & Flutter work.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS v4
- Motion

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm start
```

## Content

Edit `src/data/site.ts` for projects, testimonials, links, and copy.
